inline

Wyświetla element w linii, height i width nie mają znaczenia. Domyślna opcja. 
        .inline {
        border: 1px solid orange;
        display: inline;
        padding: 3px;
        }

        .inline span {
        border: 1px solid red;
        }

inline-block

Element jest formatowany jak inline, ale można ustawić width i height. 
        .inline-block {
        display: inline-block;
        border: 1px solid orange;
        width: 60%;
        height: 10%;
        overflow: auto;
        resize: both;
        }

        .inline-block h2 {
        border: 1px solid red;
        }
